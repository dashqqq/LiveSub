## [0.1.0-preview] - Unreleased

### Added

- Native Windows system-audio capture through WASAPI loopback.
- Local live English subtitles for Russian, Japanese, Hindi, and English input paths.
- Stateful Silero VAD and accumulated automatic language identification.
- Partial/final recognition with source-language final transcription.
- Terminology, session glossary, translation memory, semantic critical-token checks, and bounded verification.
- Native always-on-top subtitle overlay with drag, lock/click-through, monitor, style, and optional bilingual controls.
- CUDA acceleration with CPU fallback and startup warm-up checks.
- Bounded capture/inference/UI queues and developer diagnostics.
- Accuracy benchmark harness, curated model registry schemas, and language-pack manifests.
- Self-contained per-user Windows installer engineering build.
