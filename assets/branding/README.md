# LiveSub branding assets

`livesub-logo.png` is the owner-supplied LiveSub master for the v0.1.0 Preview.
It is preserved byte-for-byte; its SHA-256 is
`4df2d094fb5d4ba79639358b659e6fd4a93c10363b2e75acbb65bf4adff4ec5e`.

The application assets are derived from the left-hand symbol without changing
the mark:

- `livesub-logo-header.png` removes only the master canvas whitespace for the
  GitHub README hero.
- `livesub-icon.png` is the transparent 512 x 512 application symbol.
- `livesub.ico` contains 16, 24, 32, 48, 64, 128, and 256 pixel images.
- `livesub-icon.rgba` is the 256 x 256 straight-alpha pixel source embedded by
  the egui window so its taskbar/window identity matches the executable.

Do not replace, redraw, recolor, or recompress the master without explicit
owner approval.
