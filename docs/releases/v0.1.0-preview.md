# LiveSub v0.1.0 Preview

LiveSub creates live English subtitles from supported foreign-language audio playing on a Windows PC. It captures the system output directly, so captions do not depend on the website, stream, game, voice application, or media player providing them.

## Included

- Russian to English Preview path
- Japanese to English Preview path
- Hindi to English Preview path
- English transcription
- Windows WASAPI system-audio capture
- automatic language detection
- floating native subtitle overlay
- optional bilingual source and English display
- local inference
- compatible NVIDIA GPU acceleration
- CPU fallback
- subtitle stabilization and accuracy safeguards

## Preview notice

This is an early Preview intended for testing. It is not a stable or accuracy-certified release. Human-reviewed per-language benchmarks, broader Hindi/Hinglish validation, full production Language Packs, code signing, long-run validation, and repository-absent clean-machine certification are still in progress.

The installer is unsigned, so Windows may identify it as an unknown publisher. Do not disable Windows security. If policy blocks unsigned applications, wait for a signed release.

## Privacy

Normal speech recognition and translation run locally. The Preview does not upload raw audio or transcripts and has no telemetry integration. Network access is required to download the release; future model downloads, update checks, or optional online services will be documented separately.

## Installation

1. Download `LiveSub-Setup.exe` and `LiveSub-Setup.exe.sha256` from this release.
2. Verify the SHA-256 value.
3. Run the installer.
4. Launch LiveSub, start subtitles, and play supported foreign-language media.

The installer is designed to be self-contained; end users should not install Python, Node.js, Rust, FFmpeg, the CUDA Toolkit, or development tools manually.

## Known issues

- Accuracy varies with language, accent, speech rate, audio quality, music, and overlapping speakers.
- Hindi/Hinglish requires additional real-world validation.
- The bundled route is not yet the final evidence-selected route for each language.
- CPU performance and broad GPU/driver compatibility are not fully certified.
- Exclusive fullscreen, secure desktops, protected surfaces, and some anti-cheat environments may prevent the overlay from appearing.
- The consumer Language Library is not released.
- The installer is unsigned.
